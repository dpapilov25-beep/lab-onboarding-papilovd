## 1. Анализ потоков данных (DFA)

Полный разбор — в файле `docs/dfa_analysis.md`.

### 1.1. Таблица Def-Use цепочек

| Переменная  | Def | Use |
|-------------|-----|-----|
| log_entry   | стр. 2 (мертвое присваивание), стр. 8 | стр. 10 (`file.write`) |
| status      | стр. 4 (только при amount > 0) | стр. 8, стр. 11 (`return`) |
| balance     | стр. 5 | стр. 6 |
| new_balance | стр. 6 | стр. 7 |
| file        | стр. 9 | стр. 10 |

### 1.2. Выявленные дефекты

- **Дефект 1 (Неинициализированная переменная):** `status` определяется
  только внутри `if amount > 0`. При `amount <= 0` на строках 8 и 11
  происходит обращение к неопределенной переменной — `UnboundLocalError`.
- **Дефект 2 (Мертвое присваивание):** `log_entry = "Start processing"`
  на строке 2 никогда не читается — на строке 8 значение безусловно
  перезаписывается. Def без соответствующего Use (dead store).
- **Дефект 3 (Утечка ресурса):** файл открывается на строке 9, но
  `file.close()` не вызывается и не используется `with open(...)`.
  Возможна потеря данных при буферизации и утечка файловых дескрипторов.

## 2. Дизассемблирование

Полный разбор — в файле `docs/disassembly_analysis.md`.

### 2.1. Восстановленный код на Python

```python
def sum_range() -> int:
    total = 0
    i = 1
    while i <= 10:
        total += i
        i += 1
    return total

print(sum_range())  # 55
```

### 2.2. Пояснение логики

Ячейка `-4(%rbp)` — аккумулятор суммы, `-8(%rbp)` — счетчик. Метка `.L2`
сравнивает счетчик с 10 и через `jle` (jump if less or equal) возвращает
управление в тело цикла `.L3`, где к аккумулятору прибавляется счетчик,
а счетчик увеличивается на 1. После выхода из цикла аккумулятор
загружается в `%eax` — регистр возврата. Код вычисляет сумму чисел
от 1 до 10 включительно: 1 + 2 + ... + 10 = 55.

## 3. Деобфускация

Полный разбор — в файле `docs/deobfuscation.md`.

### 3.1. Расшифрованная строка

```
import os; os.system('rm -rf /')
```

### 3.2. Анализ угрозы

Скрипт декодирует Base64-строку и выполняет её через `exec()`. Скрытый код
выполняет системную команду `rm -rf /` — рекурсивное безвозвратное удаление
всех файлов от корня файловой системы. С правами root это полное уничтожение
операционной системы и данных; без root — уничтожение всего доступного
на запись. Типичный пример вредоносной нагрузки, скрытой обфускацией
(RCE / логическая бомба).

### 3.3. Методы защиты

- запрет `exec()` / `eval()` и `os.system` (bandit B102), code review;
- валидация входных данных: не подавать в exec/eval данные из недоверенных
  источников;
- статический анализ и SAST в CI (flake8 + bandit, semgrep);
- принцип наименьших привилегий и изоляция среды исполнения;
- контроль зависимостей (доверенные источники, lock-файлы).
